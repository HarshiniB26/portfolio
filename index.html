Systems I built

Three systems, each with a score.

01

Agentic Research Assistant

  1. Planner
  2. Search
  3. Critic
  4. Writer

A single prompt is a weak research process. The Planner splits the question, Search retrieves live sources through Tavily, a Critic decides whether those sources deserve to be used, and a Writer returns a structured report. Tools connect through the Model Context Protocol. FastAPI streams the answer. Two hundred-plus queries ran in LangSmith, and the graph changed where the failures clustered.

LangGraph · OpenAI · Tavily · MCP · FastAPI · Python · LangSmith

200+queries evaluated, then used to change the graph

02

Domain-adaptive RAG

  1. PubMedQA
  2. LoRA
  3. FAISS
  4. Scored answer

General retrieval was not accurate enough for clinical literature. I fine-tuned Mistral-7B on PubMedQA with LoRA, then retrieved over that literature with FAISS. Weights & Biases tracked accuracy, hallucination rate, and retrieval precision against a retrieval-only baseline. The combined approach gained 18 F1 points.

LlamaIndex · LoRA · Mistral-7B · FAISS · Hugging Face · Weights & Biases

+18F1 over baseline RAG

03

LLM evaluation harness

  1. GPT-4o
  2. Claude
  3. Five tasks
  4. A decision

Choosing a model from a demo is how a team gets stuck. The harness benchmarks GPT-4o and Claude 3.5 Sonnet on summarization, reasoning, RAG, code generation, and tool use. Custom metrics cover factual accuracy, hallucination rate, and response quality across 500+ cases in Braintrust and LangSmith. Streamlit shows the trade-off before a model is chosen.
